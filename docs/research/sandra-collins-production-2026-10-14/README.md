The narrative and charts draw on Scott’s firsthand account. Cream shares the confirmed Pro Tools/Mbox and Rane MP22 setup, but does not yet have a separate chart. The detailed Tranceport finishing chain is scoped to that album. Perfecto’s external mastering studio and engineer remain pending printed-credit verification.

Product images illustrate the tools rather than the recording sessions. Source credits appear beside the images. These pages are static review artifacts, separate from the deployed portfolio.

To preview locally, run `python3 -m http.server 8769 --bind 127.0.0.1` from this directory and open `/perfecto-workflow/index.html` or `/signal-flow/tranceport3-signal-flow.html`. Choose another local port if 8769 is already in use.
